Chinese Lunar Calendar for Mac

Mac 状态栏万年历

zSMTH — Android Client for NewSMTH

水木社区 BBS 开源 Android 客户端

A clean, ad-free Android client for NewSMTH (Tsinghua BBS). Features rich-text post rendering with inline GIFs, full-screen image viewer with EXIF info, Like display, IP geolocation, push notifications for replies and mentions, and board search with partial Chinese matching.

无广告、开源的水木社区客户端。支持图文混排、GIF 动画、图片 Exif、IP 来源、消息提醒、版面快速搜索及分享到微信/微博。

Android Accessibility Open Source

Android Touch Helper

开屏跳过 — 自动跳过开屏广告

An Android accessibility service that automatically skips splash-screen ads across apps. Supports three detection strategies: keyword matching, target widget lookup, and coordinate-based tap — configurable per app with no root required.

基于 Android 无障碍服务，自动跳过应用开屏广告。支持关键字、控件 ID、坐标三种跳过策略，免 root，可按应用配置。

象棋鱼 — Chess Fish

开源免费的安卓版象棋学习工具

A free, open-source Chinese Chess (Xiangqi) learning app for Android, powered by the Pikafish engine. Features move history display, legal move highlighting, engine-assisted move suggestions with one-tap selection, evaluation curves, and built-in XQF game library.
